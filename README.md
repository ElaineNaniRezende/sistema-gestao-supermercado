# Sistema de Gestão de Supermercado

Sistema de gerenciamento de supermercado desenvolvido como projeto de **Atividades Curriculares de Extensão I**.

## 📋 Sobre o projeto

O projeto tem como objetivo desenvolver um sistema para auxiliar no gerenciamento das atividades de um supermercado, tendo como foco inicial a organização e o controle de estoque.

Atualmente, os processos do estabelecimento são realizados predominantemente de forma manual. A proposta é informatizar esses processos, centralizando as informações e facilitando o acesso e o gerenciamento dos dados.

As funcionalidades do sistema serão definidas e aprimoradas durante o levantamento e a especificação dos requisitos.

## 🎯 Objetivos

- Melhorar o controle de estoque;
- Centralizar as informações do supermercado;
- Reduzir a dependência de controles manuais;
- Facilitar o acompanhamento das movimentações de produtos;
- Auxiliar na organização dos processos do estabelecimento;
- Fornecer informações que possam auxiliar na tomada de decisões.

## 📦 Funcionalidades

As funcionalidades serão definidas durante a etapa de levantamento e validação dos requisitos.

### Funcionalidade principal identificada

- Controle e gerenciamento de estoque.

### Possíveis funcionalidades

- Cadastro de produtos;
- Controle de entrada e saída de produtos;
- Controle de estoque mínimo;
- Controle de validade;
- Cadastro de fornecedores;
- Registro de compras;
- Registro de vendas;
- Controle de caixa;
- Relatórios;
- Gerenciamento de usuários e permissões.

> As funcionalidades apresentadas como possibilidades serão avaliadas e validadas durante o desenvolvimento do projeto.
